Model version v1.0
Date октябрь 2026
Currency UZS / USD

Интерактивная финансовая модель продукта, который превращает регулярные денежные переводы из-за рубежа в подтверждённый доход для доступа к кредитам. Целевой рынок — $18,9 млрд годового притока переводов, из которых 51,7% идёт напрямую на карты физлиц. Модель сочетает транзакционный скоринг, партнёрство с банками и интеграцию с активами Агентства по управлению государственными активами.
